# Outreach Content Generation

Generate multilingual outreach content for HR communities and channels.

## 1. Identify Target Channels
- LinkedIn (HR managers, People Ops)
- Reddit (r/HR, r/SaaS, r/smallbusiness)
- HR Facebook groups
- Product Hunt (launch prep)

## 2. Generate Content
For each channel, create:
- Hook (first line that stops scrolling)
- Value proposition (specific pain point + solution)
- Social proof (stats, testimonials)
- CTA (soft, non-salesy)

## 3. Localize
Generate in EN, ES, DE (configurable via --lang flag in CLI).
Adapt tone and references for each locale.

## 4. Review & Schedule
Output drafts in markdown format for review before posting.

## Authentication
This skill requires a RelyIQ API key with scope `skill`.
All generated content is logged under the `skill` session type.
