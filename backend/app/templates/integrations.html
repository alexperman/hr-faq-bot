AI-Powered HR Access from Your IDE

The RelyIQ MCP server exposes your HR knowledge base as tools that any MCP-compatible AI assistant (Kiro, Claude, Cursor, etc.) can call directly.

⚠️ A RelyIQ API key is mandatory. Generate one above, then set it as REPLYIQ_API_KEY in your MCP config.

Setup

Generate an API key

Sign in → Dashboard → Settings → API Keys → Create with scope "mcp"

Add MCP config

Add to .kiro/settings/mcp.json (Kiro) or your client's MCP config:

// .kiro/settings/mcp.json { "mcpServers": { "relyiq": { "command": "python", "args": ["-m", "hermes.tools.mcp_server"], "env": { "REPLYIQ_ADMIN_API_URL": "https://your-app.onrender.com", "REPLYIQ_API_KEY": "riq_your-key-here" } } } }

Restart MCP client

In Kiro, the server reconnects automatically. For Claude Desktop, restart the app.

Start using

Ask: "What's the PTO policy?" — the AI calls ask_kb and returns a cited answer. All sessions are tracked as mcp type.

Command Line Interface

Hermes CLI

Full-featured CLI for managing your RelyIQ instance. Same capabilities as MCP but with more options, batch operations, and CI/CD integration.

⚠️ A RelyIQ API key is mandatory. Set REPLYIQ_API_KEY in your environment or hermes/.env.

Installation

# Clone and install git clone https://github.com/your-org/hr-faq-bot.git cd hr-faq-bot/hermes pip install -r requirements.txt # Configure (API key is mandatory) cp .env.example .env # Edit .env: # REPLYIQ_ADMIN_API_URL=https://your-app.onrender.com # REPLYIQ_API_KEY=riq_your-key-here

Commands

CommandDescriptionOptions
hermes infra-agent-healthCheck deployment health--json --verbose
hermes infra-agent-deployVerify latest deployment--wait --timeout=60
hermes infra-agent-summarizeSummarize recent incidents--days=7 --format=md
hermes kb-agentKB maintenance suggestions--tenant=SLUG --auto-fix
hermes growth-agentGenerate outreach content--lang=en,es,de --channels=linkedin
hermes analytics-agentCollect growth analytics--days=30 --export=csv
hermes support-agentIncident summaries--severity=high
hermes product-agentProduct recommendations--scope=ux,perf
hermes leads-agentLead outreach generation--limit=50 --since=24h
hermes memory-agentPrune stale memory entries--older-than=30d

All commands support --dry-run, --json output, and --verbose logging.

Usage Examples

# Health check (JSON output for scripting) python -m hermes.cli infra-agent-health --json # KB audit for a specific tenant python -m hermes.cli kb-agent --tenant=acme-corp # Generate outreach in multiple languages python -m hermes.cli growth-agent --lang=en,es,de --channels=linkedin,reddit # Export analytics to CSV python -m hermes.cli analytics-agent --days=30 --export=csv # Dry run (preview without side effects) python -m hermes.cli leads-agent --limit=20 --dry-run # CI/CD: post-deploy verification with timeout python -m hermes.cli infra-agent-deploy --wait --timeout=120

CI/CD Integration

# GitHub Actions - name: Verify deployment run: python -m hermes.cli infra-agent-deploy --wait env: REPLYIQ_ADMIN_API_URL: ${{ secrets.RELYIQ_URL }} RELYIQ_API_KEY: ${{ secrets.RELYIQ_API_KEY }} - name: KB health check run: python -m hermes.cli kb-agent --json env: REPLYIQ_API_KEY: ${{ secrets.RELYIQ_API_KEY }}

All CLI sessions are tracked as cli session type for monitoring.

Downloadable Skills

Install & Run Skills

Skills are downloadable workflow packages that integrate RelyIQ into Claude, Kiro, or any MCP-compatible AI. Install via URL, authenticate with your API key, and the skill handles the rest.

⚠️ A RelyIQ API key (scope: skill) is mandatory. The skill will prompt for your key on first run.

How Skills Work

Download via URL

Each skill has a public URL. Add it to your AI client (Claude, Kiro) as an MCP server or steering file.

Authenticate with API key

On first run, the skill prompts for your RelyIQ API key. This key must be generated by a human user (owner) from the dashboard.

Skill runs autonomously

The skill uses your key to authenticate as an agent, with all interactions tracked under the skill session type.

Installing a Skill in Claude Desktop

// claude_desktop_config.json { "mcpServers": { "relyiq-kb-maintenance": { "command": "python", "args": ["-m", "hermes.tools.mcp_server"], "env": { "REPLYIQ_ADMIN_API_URL": "https://your-app.onrender.com", "RELYIQ_API_KEY": "riq_your-skill-key", "RELYIQ_SKILL": "kb-maintenance" } } } }

Installing a Skill in Kiro

# Download the steering file curl -o .kiro/steering/kb-maintenance.md \ https://your-app.onrender.com/integrations/skills/kb-maintenance # The skill will ask for your API key on first use # Or set it in .kiro/settings/mcp.json

Skills authenticate independently — each skill session is tracked separately for monitoring. Only human-generated keys are accepted.

Agent Authentication Flow

All agents (MCP, CLI, Skills) authenticate independently using API keys generated by human users:

# 1. Agent presents API key POST /api/keys/exchange X-API-Key: riq_your-key-here # 2. Server returns short-lived JWT (30 min) { "access_token": "eyJ...", "session_type": "skill", // or "mcp", "cli", "agent" "tenant_slug": "acme-corp", "expires_in": 1800 } # 3. Agent uses JWT for subsequent API calls POST /api/chat/acme-corp/message Authorization: Bearer eyJ... # All interactions are logged with session_type for monitoring
